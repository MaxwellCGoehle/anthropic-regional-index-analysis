# Anthropic Regional Index Analysis
Using the Anthropic Economic Index this project models how state level labor dynamics, industry, and infrastructure predict the scale of AI adoption as well as the structural choices in how it is deployed.

Created by Maxwell Goehle for VCU Data Science Capstone Fall 2026 semester.
